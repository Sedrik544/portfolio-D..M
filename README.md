# Portfolio – David Moravec

Osobní portfolio frontend vývojáře vytvořené pomocí HTML, CSS a JavaScriptu.

## Použité technologie

- HTML5
- CSS3
- JavaScript
- Formspree
- GitHub Pages

## Funkce

- Responzivní design
- Mobilní navigace
- Typewriter animace
- Reveal animace při scrollování
- Kontaktní formulář
- Ukázky projektů

## Spuštění lokálně

Stačí otevřít soubor `index.html` v prohlížeči.
